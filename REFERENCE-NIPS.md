# REFERENCE-NIPS

Inventory date: 2026-09-28.

This inventory separates product support from dependency presence. A NIP is marked implemented when local source shows Nosu, Armada, or Ditto Relay actively parses, writes, serves, or enforces the behavior. It is marked read-only when local source consumes or renders the NIP but does not publish it, partial when only a subset is wired, dependency-only when the code relies on the NIP as a helper or transport detail, and advertised when a relay NIP-11 document reports support that was not otherwise re-tested here.
